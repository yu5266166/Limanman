# 余先生与Limanman

这是大作家余先生与Limanman合作的第一个开源项目，包含以下三个 AstrBot 插件：

1. **astrbot_plugin_helper**：主动缓存清理插件。
2. **astrbot_plugin_helper2**：自动缓存清理插件。
3. **astrbot_plugin_send_tool**：高级消息代发工具。
